# TACIT: three-minute execution-readiness walkthrough

Use TACIT 0.4 at desktop width, Known setup, Readiness controller and seed 1847. The release address is [tacit-workbench.pages.dev](https://tacit-workbench.pages.dev); verify its release metadata against the delivery report before recording. No claim of target completion, biological validation or fabrication readiness belongs in this walkthrough.

**0:00–0:30 — One instruction, hidden decisions.** “Remove the wash without disturbing the pellet” requires orientation history, evidence about liquid and pose, a complete instrument path, and a stopping rule. Start Run procedure. The warm 3D scene is explanatory; the timestamped camera cards contain the controller's separate synthetic evidence. Show the live next-action reason.

**0:30–1:05 — Progress with a bound.** Allow playback to reach the stop, or scrub to its end. The default case removes about 580 µL and retains about 256 µL. Say that the target was not attained. A stop after progress is different from a completed task.

**1:05–1:45 — Inspect the actual decision.** Open Investigate, First blocker, then Inspect recorded inputs & alternatives. Show full-stroke immersion, the pellet exclusion envelope, the candidate count, each candidate's checks and threshold plots, and source availability timestamps. “This receipt was recorded at decision time, before the action. It says what the bounded search tried; it does not prove all possible actions would fail.” Step to the preceding decision to show the change.

**1:45–2:25 — Change one thing.** Open Design, Context, Run paired comparison. Both arms share the same initial world; only access to history changes. Use the shared volume scale to show removal, retained wash and the residual target, then inspect either arm. The selected episode is illustrative. Below it, the frozen exploratory study retains every stop. Switch to Policy to show greater bulk progress across 36 scenes alongside zero target completions. Use the zero-referenced interval plot to compare effects: access to the overhead view reduces mean retained wash by about 57 µL, with a paired 95% interval of about 11–109 µL. Keep that finite synthetic population and its zero-completion result explicit.

**2:25–3:00 — Evidence that travels.** Export paired evidence. Import that same file: both arms, camera pixels, receipts and limitations return. Point out the evidence ledger: implementation checked, independent optics challenged, physical performance unmeasured. Research geometry is secondary and explicitly not for fabrication.

Close with the connection: TACIT turns tacit procedural context into inspectable execution evidence. The contribution is making the relationship between information, constraints, actions and failure understandable and reproducible.
