# TACIT: three-minute execution-readiness walkthrough

Use TACIT 0.4 at desktop width, Known setup, Readiness controller and seed 1847. The release address is [tacit-workbench.pages.dev](https://tacit-workbench.pages.dev). For a first visit, use the [beginner walkthrough](start-here.md). This script demonstrates a synthetic experiment, without a claim of target completion, biological validation or fabrication readiness.

**0:00–0:30 — One instruction, hidden decisions.** “Remove the wash without disturbing the pellet” requires orientation history, evidence about liquid and pose, a complete instrument path, and a stopping rule. Click **Run simulation**. The 3D scene shows simulator state; the timestamped camera cards contain separate synthetic snapshots available to the controller. Show the current action's reason. If the replay is paused, use the timeline's **Replay** button; computing and replaying are separate actions.

**0:30–1:05 — Progress with a bound.** Allow playback to reach the stop, or scrub to its end. The default case removes about 580 µL and retains about 256 µL. Say that the target was not attained. A stop after progress is different from a completed task.

**1:05–1:45 — Inspect the actual decision.** Open **Investigate → First blocker**. The default stop reports that none of four tested withdrawals passed every check: pellet exclusion blocked four; hardware clearance blocked one. Use **Inspect a searched alternative** to view one proposal's checks and threshold plots. Open **Show observations and tested alternatives** for evidence and availability timestamps. “This receipt records what was available at the decision. These rejected proposals were not executed; the bounded search does not prove all possible actions would fail.” Use the decision arrows to revisit the preceding action.

**1:45–2:25 — Change one thing.** Open **Design → Policy → Run paired comparison**. A is Fixed + preflight; B is Readiness controller. The default known-scene pair removes about 219 µL more in B at a cost of 10.6 additional simulated seconds; both stop. Use the shared volume scale, then **Inspect this arm** if needed. Distinguish this illustrative pair from **Results across the assigned scenes**: the saved 36-pair evaluation averages +262.2 µL removed and +15.8 seconds, with zero completions in either arm. The per-pair plot retains all results, including the three cases with less removal in B. Context and Observation change history access and camera availability instead; each new illustrative pair requires **Run paired comparison**. The optional cross-intervention interval plot is inside **All-family mean effects across the three interventions**.

**2:25–3:00 — Evidence that travels.** In Design, click **Export paired evidence**. Go to **Investigate → Import a saved trace** and choose that same file; return to Design to see both restored arms. Their camera pixels and receipts are retained. Point out the evidence ledger: implementation checks, an independent optical audit with 6/12 covered intervals and 0/4 detected pellets, and no physical comparison. Research geometry is secondary and explicitly not for fabrication.

Close with the connection: TACIT turns tacit procedural context into inspectable execution evidence. The contribution is making the relationship between information, constraints, actions and failure understandable and reproducible.
